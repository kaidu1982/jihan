# 지한이의 작은 오락실 · 작은 도전, 커다란 모험

공개 게임: **https://jihan-games.kaidu1982.workers.dev**

첫 화면에서 **여러 게임을 고르는** HTML5 오락실입니다. 휴대폰·태블릿·PC 화면을 지원합니다. 무한계단에서는 지한이 카툰 캐릭터로 계단을 오르고, 미니 카트에서는 세 차선 도로를 달리며 별을 모읍니다. 2026-09-20 기존 Cloudflare 계정의 무료 요금제에 배포했습니다.

## 실행과 배포

Node.js 22 이상과 npm을 사용합니다. Node.js 24에서 검증했습니다.

```sh
npm ci
npm run dev
```

`http://localhost:5173`에서 게임과 로컬 점수 API가 함께 실행됩니다. 로컬 순위표는 `.local/leaderboard.json`에 저장되며 공개 서버 순위표와 별개입니다.

```sh
npm test
npm run build
npm run deploy
```

`npm run deploy`는 로그인된 Cloudflare 계정에 `wrangler.jsonc`의 `jihan-games` Worker만 배포합니다. 데이터베이스는 재생성하지 않으며 기존 운영 비밀값도 유지합니다. Cloudflare 로그인이 만료되면 `npx wrangler login`으로 다시 연결합니다. GitHub 자동 배포는 설정하지 않았습니다.

Cloudflare와 동일한 로컬 환경을 확인하려면 `.dev.vars`에 로컬 전용 `SESSION_SECRET`을 32자 이상의 임의 문자열로 준비하고 다음을 실행합니다.

```sh
npm run build
npm run db:local
npm run dev:cloudflare
```

게임 주소는 `http://localhost:8787`입니다. 이 환경의 순위표도 로컬에만 저장됩니다. 서버 코드 변경은 Wrangler가 자동 반영하며 정적 화면 변경은 빌드 후 반영됩니다.

## 배포 구성

| 구분 | 리소스 |
| --- | --- |
| Cloudflare 계정 | 기존 계정 `a6e721fd7973ae84dacafb13aacc2348` |
| Worker | `jihan-games` |
| 공개 주소 | `https://jihan-games.kaidu1982.workers.dev` |
| 게임 파일 | Workers Static Assets의 `dist/` |
| 점수 API | 같은 주소의 `/api/*` |
| 데이터베이스 | D1 `jihan-games-scores`, APAC |
| 운영 비밀값 | Worker Secret `SESSION_SECRET` |

게임 전용 Worker와 D1을 새로 만들었습니다. 기존 `hanjanpedia` Worker, 도메인, 데이터베이스 설정은 변경하지 않았습니다. 무료 사용량 한도는 같은 계정의 다른 서비스와 공유합니다.

정적 게임 파일 요청은 Worker 실행을 거치지 않습니다. API만 Worker를 실행하며, D1의 `leaderboards` 테이블 한 행에 최대 100개 기록을 저장합니다. 동시에 들어온 제출은 revision 조건부 갱신과 재시도로 충돌을 처리합니다. 순위에 들지 못한 점수나 기존 최고보다 낮은 점수는 데이터베이스를 갱신하지 않습니다.

운영 스키마 변경은 SQL 파일을 `migrations/`에 추가한 뒤 적용합니다.

```sh
npx wrangler d1 migrations apply jihan-games-scores --remote
```

`SESSION_SECRET`은 공개 파일이나 Git에 넣지 않습니다. 변경하면 기존 게스트와 진행 중인 경기의 서명이 무효화되므로 임의로 교체하지 않습니다. `.dev.vars`, `.local/`, `.wrangler/`는 Git에서 제외합니다. 사진 원본은 공개 배포 폴더에 포함하지 않습니다.

## 게임 선택과 미니 카트

- `/`: 무한계단과 여러 미니 게임을 그림 카드로 선택하는 첫 화면.
- `/?game=stairs`: 기존 무한계단. 모험·연습·오늘의 계단·도전과 순위표를 제공합니다.
- `/?game=kart`: 새 미니 카트. 각 게임의 ‘게임 고르기’로 첫 화면에 돌아갑니다.

미니 카트는 자동으로 달리는 자동차를 왼쪽·오른쪽 버튼이나 키보드 ←/→, A/D로 조작합니다. 약 1분의 주행을 마치면 완주하며, 장애물에 부딪혀도 잠깐 느려진 뒤 계속 달립니다. 별을 모으고 완주·별 수집·충돌 없는 주행에 도전할 수 있습니다.

초록 초원·노을·눈길의 세 코스와 기본 카트·소방차·공룡차·우주차를 제공합니다. 모은 별로 자동차를 열고 선택하며, 자동차는 외형만 달라집니다. 카트 기록과 수집 정보는 현재 브라우저에 저장되며 다른 기기로 동기화하지 않습니다. 미니 카트는 기존 계단 순위표 API에 기록을 제출하지 않습니다. 소방차·공룡차·우주차의 해제 비용은 각각 20·35·50별이고, 이미 만난 자동차를 다시 선택할 때는 별을 차감하지 않습니다. 무한계단의 캐릭터 관리에서 캐릭터를 삭제하면 같은 이름의 카트 기록도 함께 삭제합니다.

일시정지·재개·다시 하기와 소리 설정을 지원하고, 탭 전환이나 창 비활성화 시 자동으로 멈춥니다. 코스와 자동차는 게임 안에서 직접 그리며 외부 이미지나 캐릭터를 내려받지 않습니다.

## 미니 모험

공룡 달리기를 포함한 미니 모험은 큰 조작 버튼과 키보드, 화면 터치를 지원합니다. 게임 도중 다른 탭으로 가거나 창이 비활성화되면 자동으로 멈춥니다. 일시정지·재개·다시 하기, 소리 설정, 무료 코스 선택과 모은 별로 친구를 고르는 수집함을 제공합니다.

| 주소 | 게임 | 놀이 방법 |
| --- | --- | --- |
| `/?game=dino` | 공룡 달리기 | 점프 한 버튼으로 바위와 구덩이를 넘고 알을 모아 약 50초의 숲길을 완주합니다. |
| `/?game=space` | 우주 탐험 | 운석을 피해 좌우로 날며 길 잃은 우주 친구들을 구조하고 54초 뒤 정거장에 도착합니다. |
| `/?game=maze` | 보물 미로 | 시간 제한 없이 7·9·11칸의 정원에서 열쇠와 보석을 찾고 보물상자를 엽니다. H 키나 힌트 버튼으로 다음 방향을 알 수 있습니다. |
| `/?game=crossing` | 길 건너기 | 방향키나 네 버튼으로 10·14·18칸의 마을을 건넙니다. 차에 닿으면 가까운 풀밭에서 다시 시작하며 모은 별은 유지됩니다. |

미니 모험 기록은 `jihan-mini-adventures-v1` 키로 이름별·게임별로 현재 브라우저에 저장됩니다. 완주 때만 별을 수집함에 지급하고 같은 경기를 중복 지급하지 않습니다. 친구는 모습만 바뀌며, 해제한 친구를 다시 고를 때는 별을 쓰지 않습니다. 저장 공간을 사용할 수 없으면 지금 창에서만 기록을 기억한다고 안내합니다. 무한계단에서 캐릭터를 삭제하면 같은 이름의 미니 모험 기록도 지웁니다. 온라인 순위표로 제출하지 않습니다.

## 무한계단 게임 방법

- **오르기:** 바라보는 방향으로 한 계단. 오른쪽 화살표, D, Space로도 조작합니다.
- **방향 바꾸기:** 반대로 돌아서 한 계단. 왼쪽 화살표 또는 A로도 조작합니다.
- **도전 모드:** 제한 시간 내 올라가며 성공할 때마다 시간이 보충됩니다. 잘못된 방향이나 시간 초과로 종료됩니다.
- **세계 모험:** 구름 초원 → 노을 언덕 → 반딧불 숲 → 눈꽃 봉우리 → 별빛 우주를 차례로 여행합니다. 목표는 각각 30·50·75·100·150계단이며, 시간 제한 없이 세 번 실수하면 종료됩니다. 완주하면 다음 모험이 열립니다.
- **오늘의 계단:** 한국 날짜를 기준으로 매일 같은 경로에 도전합니다. 도전 모드의 시간 규칙으로 최대 150계단까지 오르며, 날짜별 개인 최고는 이 브라우저에만 저장합니다.
- **연습 모드:** 시간 제한과 추락 없이 계단을 익힙니다. 일시정지 후 처음으로 돌아가면 연습 최고 기록을 기기에 저장합니다.
- 소리 설정, 일시정지/재개, 다시 하기, 여러 캐릭터 선택, 캐릭터와 순위 기록 삭제를 지원합니다.
- 탭을 떠나거나 창이 비활성화되면 자동으로 일시정지합니다.

검은 후드티·회색 바지·빨간 운동화 캐릭터의 투명 PNG를 이동·반전·회전해 점프를 표현합니다. 경기당 최대 5,000계단이며, 온라인 기록은 시작 후 30분 이내에 제출합니다.

도전·연습·오늘의 계단에서는 50계단마다 다섯 풍경이 순환하고, 세계 모험에서는 해당 지역의 풍경이 유지됩니다. 각 지역의 배경·장식과 동행 친구는 게임 안에서 직접 그립니다. 동작 줄이기 설정에서는 화면 흔들림과 장식 애니메이션을 줄입니다.

### 모험 수첩과 수집

성공한 계단은 여러 판에 걸쳐 합산하며 10계단마다 별 하나를 얻습니다. 모험 첫 완주, 배지 8종, 오늘의 미션 3종도 별을 줍니다. 보상은 조건을 달성하면 자동으로 지급되며, 같은 보상을 중복 지급하지 않습니다. 매일 미션은 한국 자정에 바뀌며 자정을 넘겨 끝난 경기는 시작한 날짜를 기준으로 처리합니다.

모험 수첩에서 지역을 선택하거나 별로 동행 친구를 만날 수 있습니다. 몽실 구름은 기본 친구이며 초록 새싹·반짝 별·달빛 토끼·꼬마 혜성·우주 탐험가를 추가로 수집할 수 있습니다. 친구는 외형만 바뀌며 점수와 게임 난이도에는 영향을 주지 않습니다. 결제는 없습니다.

모험 진행, 별, 친구, 배지와 미션은 캐릭터별로 현재 브라우저에 저장합니다. 새로고침 후에도 이어지지만 다른 기기로 동기화하지 않습니다. 모험·오늘의 계단 기록은 기존 도전 순위표에 제출하지 않습니다.

## 배경 음악

- **도전 모드 — 통통 구름:** 128 BPM, 60초. 말렛 멜로디와 경쾌한 리듬.
- **연습 모드 — 포근한 구름:** 104 BPM, 약 74초. 같은 주제를 부드럽게 편곡.

오늘의 계단에는 도전 음악, 세계 모험에는 연습 음악이 흐릅니다.

프로젝트용으로 멜로디를 작성하고 악기 소리를 합성했습니다. 외부 음원·샘플은 사용하지 않았습니다. 각 곡은 32마디를 반복하며, 게임 시작 버튼을 누른 뒤 재생합니다. 음악과 효과음을 각각 끄고 켤 수 있고 설정은 기기에 저장됩니다. 기존에 소리를 껐던 사용자는 음악도 꺼진 상태로 유지됩니다.

일시정지와 탭 전환 시 음악이 멈추며 계속하기를 누르면 이어집니다. 다시 하기는 곡의 처음부터 시작합니다. 음원은 필요할 때만 내려받고, 다운로드에 실패해도 게임은 진행됩니다. AAC 파일은 곡당 약 1MB이며 정적 게임 파일로 배포합니다.

## 기록 보관

| 위치 | 보관 내용 |
| --- | --- |
| 브라우저 | 캐릭터 이름, 무작위 캐릭터 ID, 도전/연습 최고 점수, 소리 설정, 모험 진행·별·친구·배지·일일 미션·오늘의 계단 최고 |
| 서명된 HttpOnly 쿠키 | 같은 브라우저의 게스트 세션, 유효기간 1년 |
| 서버의 현재 순위표 | 도전 모드 상위 100명의 캐릭터별 최고 기록 |

같은 이름이어도 다른 브라우저의 캐릭터는 별개입니다. 이름으로 타인의 기록을 덮어쓸 수 없습니다. 기기를 바꾸거나 쿠키/브라우저 데이터를 지우면 기존 캐릭터 소유권을 복구할 수 없습니다. Google 로그인이나 서버의 회원 테이블은 없습니다.

서버에는 순위에 필요한 이름, 점수, 등록 시각, 소유권 확인용 해시, 경기 ID만 저장합니다. 전체 경기 이력과 입력 내역은 보관하지 않습니다. 101위로 내려간 기록은 같은 갱신에서 제거하며, 동점은 먼저 등록된 기록을 우선합니다. 삭제된 순위의 빈자리는 과거 101위 기록으로 채우지 않습니다.

공개 API 응답은 순위·이름·점수·본인 여부만 포함합니다. 입력 내역은 서버의 점수 검증 중에만 사용합니다. Cloudflare의 요청 메타데이터와 D1 복구용 이력은 애플리케이션 순위표와 별개이며, 애플리케이션에서 추가 경기 이력을 만들지는 않습니다.

연결에 실패해도 개인 최고 기록은 기기에 저장합니다. 실패한 온라인 제출은 자동 재전송하지 않습니다. 연결 없이 시작한 경기는 온라인 순위표에 제출하지 않습니다.

모험 진행은 성공한 계단마다 저장하며 일시정지·종료 시에도 확인합니다. 중복 보상을 막기 위한 최근 경기 처리 정보는 브라우저에 최대 128건만 유지하고, 서버에 전체 경기 이력을 추가하지 않습니다. 브라우저 저장 공간을 사용할 수 없으면 화면에 알립니다. 캐릭터 삭제 시 해당 캐릭터의 모험 진행도 함께 삭제합니다. 로컬 수집 정보는 사용자가 수정할 수 있으므로 온라인 경쟁이나 결제의 근거로 사용하지 않습니다.

## 기술과 운영

TypeScript + Vite를 사용합니다. 무한계단과 미니 카트는 Phaser 4.2.1의 WebGL을 우선 사용하고 Canvas로 대체할 수 있습니다. 공룡 달리기·우주 탐험·보물 미로·길 건너기는 가벼운 Canvas 2D 렌더링과 테스트 가능한 별도 세션 모델을 사용합니다. 메뉴·이름 입력·순위표·조작 버튼은 HTML/CSS로 구성했습니다. 서버는 Express API를 Cloudflare의 Node.js 호환 실행 환경에서 처리합니다. 이전 Firebase 배포 설정과 전용 패키지는 제거했습니다.

서명된 경기 정보와 공통 게임 규칙으로 방향·속도·시간을 다시 계산합니다. 임의 숫자만 보내는 점수 조작은 거부하지만 자동 플레이를 완전히 막는 검증은 아닙니다. 요청 제한은 실행 인스턴스별 기본 보호입니다.

배포 시 대시보드에서 Workers Free(US$0)를 확인했으며 유료 업그레이드는 하지 않았습니다. 무료 한도는 계정 기준 API 하루 100,000회, 요청당 CPU 10ms, D1 읽기 하루 5,000,000행·쓰기 하루 100,000행입니다. 한도를 넘으면 API나 순위표 기능이 제한될 수 있습니다. 게임의 정적 파일은 별도 경로로 제공합니다.

- [Workers 한도](https://developers.cloudflare.com/workers/platform/limits/)
- [정적 파일 과금](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/)
- [D1 요금](https://developers.cloudflare.com/d1/platform/pricing/)

대시보드에서 게임 Worker의 요청 수·오류·CPU 사용량과 D1 사용량을 확인합니다. Worker 로그 표본 수집은 10%이며 코드에서 쿠키·서명·이름·입력 본문을 로그로 출력하지 않습니다. 별도의 알림이나 정기 모니터링은 설정하지 않았습니다.
